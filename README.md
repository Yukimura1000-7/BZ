# 💰 ЭкономСтратегия

Веб-приложение для экономической стратегии в реальном времени с системой сессий, ролями игроков и динамическим геймплеем.

## 🚀 Быстрый старт с Docker

### Вариант 1: Docker Compose (рекомендуется)

```bash
# Собрать и запустить контейнер
docker-compose up -d --build

# Приложение будет доступно на http://localhost:3000
```

### Вариант 2: Docker напрямую

```bash
# Собрать Docker образ
docker build -t econom-strategy .

# Запустить контейнер
docker run -d -p 3000:80 --name econom-strategy econom-strategy

# Приложение будет доступно на http://localhost:3000
```

### Остановка контейнера

```bash
# Docker Compose
docker-compose down

# Docker напрямую
docker stop econom-strategy
docker rm econom-strategy
```

## 📖 Использование

### Для администратора:

1. Откройте приложение в браузере
2. Нажмите **"Вход для администратора"**
3. Войдите с учетными данными:
   - Логин: `admin`
   - Пароль: `admin`
4. Создайте игровую сессию
5. Поделитесь кодом сессии или QR-кодом с игроками
6. Управляйте игрой через панель администратора

### Для игроков:

1. Откройте приложение на телефоне
2. Нажмите **"Присоединиться к игре"**
3. Введите код сессии (или отсканируйте QR-код)
4. Введите ваше имя
5. Система автоматически назначит роль:
   - 🛒 **Покупатель** (60% игроков)
   - 💼 **Продавец** (40% игроков)
6. Начните совершать сделки!

## 🎮 Особенности

### Система сессий
- Создание игровых сессий с уникальными кодами
- QR-коды для быстрого подключения
- Возможность делиться ссылкой через Web Share API

### Роли игроков
- Автоматическое распределение ролей (60/40)
- Покупатели могут только покупать
- Продавцы могут только продавать
- Валидация сделок по ролям

### Экономика
- Балансы игроков
- Система товаров
- Курсы валют с бегущей строкой
- Автоматическая проверка баланса при сделках

### Управление игрой
- Таймер этапов с автоматической паузой
- Лидерборд в реальном времени
- Система событий
- Банковские операции
- Статистика сделок

### Мобильная адаптация
- Полная адаптация под мобильные устройства
- Safe area для iOS
- Touch-оптимизация
- PWA-совместимость

## 🛠 Технологии

- **Frontend:** React 18 + TypeScript
- **State Management:** Zustand
- **Routing:** React Router v6
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **QR Codes:** qrcode.react
- **Database & Realtime:** Supabase (PostgreSQL + Realtime)
- **Build Tool:** Vite
- **Deployment:** Docker + Nginx / Netlify / Vercel
