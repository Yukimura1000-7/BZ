# 🚀 Настройка Supabase для ЭкономСтратегии

## Проблема, которую решает Supabase

Сейчас приложение использует `localStorage`, который хранит данные только в браузере одного устройства. Когда админ создает сессию на компьютере, она существует только в его браузере. Игроки с телефонов не могут подключиться, потому что у них нет этих данных.

**Supabase решает эту проблему:**
- ✅ Центральная база данных (PostgreSQL)
- ✅ Real-time синхронизация между всеми устройствами
- ✅ Данные доступны с любого устройства
- ✅ Бесплатный тариф для небольших проектов

## 📋 Пошаговая инструкция

### Шаг 1: Создание проекта в Supabase

1. Перейди на [supabase.com](https://supabase.com)
2. Зарегистрируйся или войди через GitHub
3. Нажми **"New Project"**
4. Заполни:
   - **Name**: `econom-strategy` (или любое другое)
   - **Database Password**: придумай надежный пароль (сохрани его!)
   - **Region**: выбери ближайший к тебе (например, `Frankfurt` для Европы)
5. Нажми **"Create new project"**
6. Подожди 2-3 минуты пока проект создастся

### Шаг 2: Создание таблиц в базе данных

1. В Supabase Dashboard перейди в **SQL Editor** (иконка `</>` в левом меню)
2. Нажми **"New query"**
3. Скопируй весь код из файла `supabase-schema.sql` (в корне проекта)
4. Вставь в SQL Editor
5. Нажми **"Run"** (или Ctrl+Enter)

Должно появиться сообщение: **"Success. No rows returned"**

Это создаст:
- ✅ Таблицы: sessions, players, deals, events, currency_rates
- ✅ Индексы для производительности
- ✅ Realtime подписки
- ✅ Автоматическую генерацию кодов сессий
- ✅ Автоматическое назначение ролей (60/40)

### Шаг 3: Получение API ключей

1. Перейди в **Settings** → **API** (в левом меню)
2. Найди раздел **"Project API keys"**
3. Скопируй два значения:
   - **Project URL** (например: `https://abcdefghijk.supabase.co`)
   - **anon public key** (длинная строка, начинается с `eyJ...`)

### Шаг 4: Настройка переменных окружения

Создай файл `.env` в корне проекта:

```bash
VITE_SUPABASE_URL=https://abcdefghijk.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

**ВАЖНО:** 
- Замени значения на свои из Supabase Dashboard
- Не коммить `.env` в Git (он уже в `.gitignore`)
- Для production добавь эти переменные в Netlify/Vercel

### Шаг 5: Тестирование

1. Перезапусти dev сервер:
```bash
npm run dev
```

2. Открой приложение в браузере
3. Создай сессию как админ
4. Открой приложение на телефоне (через QR-код или код сессии)
5. Теперь данные синхронизируются в реальном времени!

## 🌍 Деплой на Netlify с Supabase

### Добавление переменных окружения в Netlify

1. Перейди в **Site settings** → **Environment variables**
2. Добавь две переменные:
   - **Name**: `VITE_SUPABASE_URL`
     **Value**: `https://abcdefghijk.supabase.co`
   - **Name**: `VITE_SUPABASE_ANON_KEY`
     **Value**: `eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...`
3. Нажми **"Save"**
4. Пересобери и redeploy сайт

## ❓ Частые вопросы

**Q: Почему не работает подключение с телефона?**
A: Потому что данные хранятся в localStorage браузера компьютера. Supabase решит эту проблему.

**Q: Нужно ли платить за Supabase?**
A: Нет, бесплатного тарифа достаточно для твоего проекта.

**Q: Как быстро работает синхронизация?**
A: Realtime обновления приходят за 100-500мс — почти мгновенно!

**Q: Что будет если Supabase упадет?**
A: Supabase имеет 99.9% uptime и автоматические бэкапы. Но для критичных данных можно добавить fallback на localStorage.
